Supabase 接続設定

最初にSupabaseのプロジェクト情報を入力してください。
入力した情報はブラウザに保存され、次回から自動接続されます。

※ Supabaseの「Project Settings → API Keys → Legacy」から取得できます。
※ このファイルはWebサーバー経由で開く必要があります（file:///では動作しません）。
　→ ファイルをサーバーにアップロードするか、VS Codeの「Live Server」で開いてください。

※ 以下のSQLでテーブルを作成してから接続してください：

create table shifts (
  id uuid primary key default gen_random_uuid(),
  date text not null,
  name text not null,
  slots text[] not null,
  updated_at timestamptz default now()
);

※ RLSはオフ、またはanon向けにSELECT/INSERT/UPDATE/DELETE許可してください。
